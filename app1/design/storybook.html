Without #app { display: contents; } in the page's <head>, the layout collapses to a narrow column: Vue mounts the sidebar/topbar/main one DOM level deeper (inside #app) than the grid in common.css expects. Every AppShell-using view needs that line — copy it from the page skeleton in COMPONENTS.md, or from any file under views/.
